# Forged-In-The-Barrens

HSdeck schema 1 카드 API. 한국 날짜(Asia/Seoul)를 사용합니다. `data/<cardID>.json`의 `card`에는 카드가 처음 사용 가능해진 시점의 스펙을, `card.patches`에는 이후 실제 변경된 필드만 기록합니다.

- `cards.json` 현재 스펙 및 기존 원화 경로 보존
- `render.json` 현재 스펙 + 과거 날짜별 변경값
- `history.json` 구버전 플러그인 호환
- `release-policy.json` 본 확장팩 및 통곡의 동굴 미니 세트 날짜
- `data/combinations/` 카자쿠스 골렘 108개 조합 변형(카드 ID 중복 등록 방지)

최초 스펙은 공식 변경 기록으로 확인한 필드 이외에는 최신 스냅샷으로 잠정 기록되어 있으며, 상태는 `card.initialSpecStatus`에 표기됩니다. **기존 원화·황금 애니메이션은 수정하지 않았습니다.**


## API 편집 지침 (2026-11-14)

- 공개 사용 자료는 `cards.json` 카드 목록, `data/<CARD_ID>.json`의 카드 정보와 한국 날짜별 기록, `art/` 일반 원화, `golden/` 황금 카드 원화·애니메이션, `frame/` 프레임·셰이더·텍스처입니다. 존재하지 않는 파일을 임의 생성하지 않습니다.
- 중복 산출물 `render.json`, `history.json` 및 `*-date.json`은 배포·커밋하지 않습니다. 검증에 필요하면 빌드 작업공간에서만 생성합니다. 신규 schema/legacy 래퍼를 추가하지 않습니다.
- `data/`가 아직 날짜 키 형식이 아니라면 최초 실제 대전 사용 가능일과 원본 필드를 교차 검증하여 무손실 변환합니다. 한국 기준 베타(북미 시간 환산), 모험 지구 개방, 이벤트 실제 개시일 및 토큰 생성 가능일을 구분합니다.
- 최초 기록 이후에는 변경된 필드만 기록하고, 오기입 날짜 키는 삭제·통합합니다. 표시용 줄바꿈은 `<br></br>`이고 원본 증거 및 황금/프레임 바이너리는 변형하지 않습니다.
- `release-policy.json`, `tools/`, `.github/` 및 실제 검증 근거를 제거하기 전에는 재생성/사용 참조를 확인합니다. 카드·프레임·황금 파일이 아닌 임시 출력물을 공개 API에 추가하지 않습니다.
